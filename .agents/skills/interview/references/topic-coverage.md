# 话题覆盖清单

用作遗漏检查，不是问卷。每个话题只需标记：已确认 / 待确认 / 不适用 / 非目标。优先问会改变架构、范围、验收或成本的问题。

以下清单适用于多数软件/agent 项目；项目类型不同时，按领域增删话题。清单中的示例不是需求。

## 1. 目标与成功标准

- 要解决的核心问题是什么？谁使用、多久用一次？
- 最小可验证的成功场景是什么？
- 明确不做什么？
- 成功如何衡量（功能、延迟、稳定性、易用性）？

## 2. 用户、角色与权限

- 有哪些用户、角色或外部系统？谁做什么？
- 权限、可见范围和数据隔离如何定义？
- 是否需要多用户、多项目、多租户或多房间？
- 角色是否会变化？谁负责管理？

## 3. 核心场景与交互

- 最重要的 3–5 个用户旅程是什么？
- 输入、输出和失败路径分别是什么？
- 哪些交互必须实时？哪些可以异步？
- 是否需要历史、搜索、通知、撤销、引用或附件？

## 4. 运行环境与接入

- 支持哪些平台、宿主或客户端：桌面、Web、CLI、IDE、移动端、其他系统？
- 如何接入：API、MCP、插件、hook、webhook、手动操作？
- 是否必须自动加入或自动发现？手动配置是否可接受？
- 允许修改外部系统配置吗？由谁负责？
- 不同环境能力不一致时如何呈现和验收？

## 5. 身份、会话与生命周期

- 身份如何确定（账号、设备、会话、角色、项目）？
- 同一用户或客户端的多个会话如何区分？重启、断线、换环境后身份是否保留？
- 会话结束或离线多久算失效？
- 是否需要邀请、注册、注销、移交？

## 6. 数据、状态与持久化

- 需要保存哪些数据？保存多久？
- 存储介质、备份和恢复要求是什么？
- 需要哪些状态？状态来源是什么（心跳、上报、事件、推断）？
- 陈旧、误报、断线如何处理和展示？
- 多项目、多用户如何隔离？

## 7. 消息、事件与路由（若适用）

- 支持哪些发送目标：单聊、群组、@单人、@多人、@全体、频道、线程？
- @ 或路由的范围与可见范围是否一致？未指定目标时谁响应？
- 历史、编辑、删除、附件、引用、排序、去重如何处理？
- 如何防止自动触发无限循环？

## 8. 投递、唤醒与延迟（若适用）

- 消息或事件如何到达消费者：拉取、长轮询、push、hook、混合？
- 可接受的延迟是多少：秒级、分钟级还是下一轮？
- 空闲或已完成当前轮的消费者是否必须被唤醒？这是硬性验收标准吗？
- 工作中收到新事件如何处理：打断、排队还是忽略？谁决定？
- 重试、确认、重复投递、丢失如何定义和处理？
- 是否接受为不同宿主或客户端分别适配？愿意维护几个适配器？

## 9. 界面与人工参与（若适用）

- 人如何加入：只读观察、操作、发言、审批、管理？
- 需要哪些界面和视图：列表、详情、状态、未读、历史、搜索、通知？
- 实时性、移动端、多窗口、权限要求？
- 发送/操作失败、重连、未读或未处理状态如何处理？

## 10. 安全与信任

- 部署边界：本机、内网还是公网？主要威胁是什么？
- 需要怎样的认证、授权和访问控制？
- 不可信输入、prompt injection、工具权限如何限制？
- 凭据和密钥如何管理？

## 11. 部署、运维与规模

- 支持哪些操作系统和运行时？安装、启动方式是什么？
- 是否常驻？开机自启、日志、监控、升级、崩溃恢复如何处理？
- 预期用户数、数据量、并发量是多少？
- 失败时用户看到什么？如何降级？

## 12. 技术栈、复用与许可证

- 语言、框架、数据库偏好是什么？维护者熟悉什么？
- 复用现有开源项目还是自建？复用哪一部分？
- 许可证是否可接受？
- 维护成本和长期演进由谁负责？

## 13. 验收、测试与原型

- 在哪些真实环境、版本或设备上验证？
- 最小原型包含哪些场景？
- 验收标准是什么？怎样算成功？
- 哪些必须实测，哪些可以静态检查？

## 14. 范围优先级与时间

- must-have、nice-to-have、later 分别是什么？
- 期望的时间线、里程碑和投入是多少？
- 如果关键能力无法实现，Plan B 是什么？

## 15. 风险与依赖

- 最大的技术不确定性是什么？
- 依赖哪些外部项目、接口或版本？
- 哪些假设一旦不成立会推翻方案？
- 需要用户提供哪些环境、资源或决策？

## 可选：多 agent / 实时协作平台补充

若项目涉及多个 AI agent、宿主接入或实时协作，额外检查：

- 支持哪些宿主或客户端？如何加入（MCP、hooks、插件、wrapper、手动命令）？
- 消息如何投递与唤醒？空闲 agent 是否必须被唤醒？
- 工作中收到消息如何处理：打断、排队还是忽略？
- @ 的可见范围与唤醒范围是否一致？如何防止 agent 之间循环触发？
- 状态来源（心跳、主动上报、宿主事件、终端推断）及其精度？
- 多 agent 的身份、会话、断线、重启后如何保持或恢复？
- 人如何观察、参与、审批和管理？
