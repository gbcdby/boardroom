# 实现执行规则

## 发现能力

读取项目指令、目标文件及调用方、依赖清单和已有测试／CI 入口，确认实际语言、运行时、工作目录与包管理器。使用项目已有命令；读过 CI 配置不表示本机已经执行。

缺工具时使用已有等价能力，或在当前授权内补齐必要依赖。不能擅自升级依赖、扩大服务或全局配置；无法补齐就记录具体未运行项。

## 小步反馈

- 将目标变成前置条件、动作和可观察结果，保留验收编号；已有检查能精确覆盖时直接复用。
- 行为缺陷先确认可重复失败来自目标行为。实施一小块变更后运行相关反馈，再决定下一块；避免先批量写完全部测试再批量写实现。
- 公共 API、异步边界、数据结构与生命周期改动要覆盖生产调用方、测试、适配器和文档。文本合并成功不证明兼容。
- 低风险文档或样式改动核对事实、链接、语法或渲染即可，仍遵守项目必要检查。测试本身过时时先给契约依据，不能靠改期望、删断言或扩大 mock 范围掩盖问题。

## 外部方法接入

本技能可独立工作。调用其他实现／TDD 技能时核对真实入口、版本、调用限制与前置条件；使用自己的方法与实际调用外部技能分别记录。

- 人工专用入口不得通过直接读盘或委托代理绕过。
- 原技能要求已确认测试边界时，保留真实确认出处；项目允许自行设计测试时可用本技能的方法，但不冒称满足原技能前置条件。
- 第三方总调度器要求子代理或任务图时，只在条件实际具备且当前任务需要时接入；本技能不强制每个小任务建立完整协作流程。

方法来源：boardroom 固定版本的 [tdd](https://github.com/gbcdby/boardroom/blob/eea2f06c72eb76e300cdd4d2270facb30c6cff49/.agents/skills/tdd/SKILL.md) 要求已确认 seam；[implement-spec](https://github.com/gbcdby/boardroom/blob/eea2f06c72eb76e300cdd4d2270facb30c6cff49/.agents/skills/implement-spec/SKILL.md) 是用户入口且要求子代理。这里借鉴行为驱动的小步反馈、契约交接与调度隔离，不假设其他项目具有相同规则，也不宣称调用 Matt 原版。

## 写入与候选身份

并行时复用同仓活动记录；开始或扩大范围前核对相关负责人、接口及实际用到的端口、数据和构建路径。可隔离的资源分开使用，独占对象按约定交接；兼容的同文件修改可在各自目录继续。没有原子能力时记录仍只是约定。保护用户已有改动，不自动 reset、clean、覆盖或 stash。

恢复时重读当前 Ticket、Spec、所有权与实际内容；不要重放旧请求。已提交候选记录提交与相关基线、设计、环境；未提交候选包含全部实际改动，用真实摘要或可重建快照标识，不能只写 HEAD。无法固定候选时说明限制。

只记录验证所需且可安全公开的环境信息，不收集完整环境变量或凭据。检查证据保留原候选身份；对象变化后重评适用范围，未变化部分可按实际影响依据复用。
