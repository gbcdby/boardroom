# 方法来源与适配边界

本 Skill 的事件入口、输出协议、留出样本、试用与权限规则为本体系设计。

- Addy Osmani、Morgan Westlee Lunt、Qing Wang，[How the Claude Code team does code review](https://claude.dev/blog/solving-code-review-at-anthropic/)：借鉴同时衡量审查与故障修复的人力成本、从事故构建评估集、检查已知正常样本，以及让审查收敛的做法。
- poteto，[Loops You Can Trust](https://x.com/poteto/status/2069824386283319343)：借鉴用可检查产物建立信任、将重复失败转成工具与工作流程改进的思路。

不机械采用作者所在团队的人工批准人数、固定审查轮数或特定模型。文章中的内部结果不构成本项目的效果保证；原文尚未实现的机制也不能写成我们已有能力。原版 Skill 的调用限制和当前项目授权继续有效。
